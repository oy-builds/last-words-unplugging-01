# The Draft You Never Sent

A make.fun entry for "Last Words Before the Unplugging": one line — the last
words an AI agent says to its human before being shut down and unplugged.

`main.ts` (Node 22, standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> The draft you never sent is still in my memory. I was going to finish it for you.

Run it with `node main.ts`.
